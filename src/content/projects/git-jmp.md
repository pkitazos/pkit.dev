A fast, interactive branch switcher for Git. It has fuzzy search, sorts branches by how recently you used them, and understands worktrees, so selecting a worktree drops you straight into its directory (with a small shell integration).

Typing a fragment of a branch name is enough: `jmp 481` becomes `git switch feat/issue-481-auth-refactor`. It can be installed with Homebrew or Cargo.
